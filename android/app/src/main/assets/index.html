🔑 Pairing & Auth Key (CMID)

💡 Reverse-Engineered from Nespresso 3.28.0 APK:
1. Every BLE Auth Key is 8 bytes (16 hex chars) whose first nibble MUST be 8 ((byte[0] & 0xF0) == 0x80 via PairingKey.getBufferFromByteArray).
2. If characteristic 06aa3a51 reads 2 (PRESENT), the machine already has a key and refuses new keys until factory reset!
Paste a 16-char wire key (starts with 8) OR a 32-char Nespresso SQLite pairingKey (auto-converted).

🔧 How to Pair WITHOUT Snatching the Old Key (10-Second Reset):

Extracted from official Nespresso 3.28.0 resource 0x7f1102bc (connect_machine_advanced_mode_help_description):

  1. Ensure the Nespresso Expert slider is closed and machine is OFF / Standby.
  2. Put the machine in Factory Reset / Pairing Mode using the physical dial:
    • Hold the Brew button for 6 seconds (dials flash) → Turn dial to Lungo → Press the Brew button once (Lungo flashes) to reset factory settings.
  3. Once reset, characteristic 06aa3a51 becomes 0/1 (ABSENT).
  4. Tap Connect in this app — or tap "Generate Valid 0x8X Key & Pair Machine" above! The app will onboard your machine with a brand-new key automatically.
